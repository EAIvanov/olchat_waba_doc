# Шаблоны

**Полноценная инструкция: Встройка шаблонных сообщений в чаты Открытой линии Олчат WABA (иконка 4 квадратиков)**

#### Введение

Олчат WABA позволяет удобно работать с **шаблонными сообщениями** WhatsApp Business API прямо внутри интерфейса Битрикс24. Один из самых удобных способов — **быстрый доступ через иконку сетки (4 квадратика)** в поле ввода сообщения чата Открытой линии. Это решение особенно полезно для менеджеров, которые часто отправляют однотипные сообщения: приветствия, уведомления, коммерческие предложения и т.д.

В этой статье мы подробно разберём:

* Как настроить функцию
* Как создавать и управлять шаблонами
* Как отправлять шаблоны через иконку 4 квадратиков
* Полезные советы и troubleshooting

#### &#x20;Предварительные требования

Перед началом работы убедитесь, что:

* У вас подключена интеграция **Олчат WABA** (официальная через GupShup).
* Шаблоны сообщений одобрены Meta (WhatsApp).
* У сотрудников есть соответствующие права доступа к шаблонам.

#### Включение встроенной панели шаблонов в чатах

Функция «Шаблоны в чате» должна быть активна:

1. Перейдите в **настройки приложения Олчат**.
2. Откройте вкладку **«Возможности»**.
3. Найдите пункт **«Шаблоны в чате»** и включите его.

**Если иконка 4 квадратиков не появляется:**

* Снимите галочку → сохраните изменения.
* Поставьте галочку заново → сохраните.
* Перезапустите приложение Олчат.
* Проверьте наличие иконки в поле ввода сообщения.

Если проблема остаётся — обратитесь в поддержку Олчат.

#### Создание и настройка шаблонов сообщений

Шаблоны создаются централизованно и доступны всем сотрудникам (в зависимости от прав).

**Путь к настройкам:**

* Левное меню портала → приложение **Олчат** → пункт **«Настройки шаблонов»**.

**Создание нового шаблона:**

1. Нажмите кнопку **«+ Создать шаблон»**.
2. Укажите **название** шаблона (удобное для поиска).
3. Введите **текст сообщения**.
4. Для вставки переменных нажмите значок **{ }** и выберите нужные поля из CRM (Контакт, Компания, Сделка, Лид и др.). Переменные автоматически подставятся при отправке.
5. Нажмите **«Далее»**.
6. При необходимости назначьте **категорию** и **права доступа**.
7. Сохраните шаблон.

**Управление категориями:**

* В окне настроек шаблонов нажмите иконку **⚙️**.
* Создавайте, редактируйте и удаляйте категории для удобной фильтрации.

Шаблоны можно редактировать и удалять прямо из общего списка.

#### Отправка шаблонных сообщений через иконку 4 квадратиков

Это основной сценарий работы в чатах Открытой линии.

**Инструкция по отправке:**

1. Откройте нужный чат в Открытой линии.
2. В поле ввода сообщения нажмите на **иконку сетки (4 квадратика)**.
3. В открывшемся окне выберите раздел **«Олчат:WA - шаблоны»**.
4. Используйте поиск или фильтр по категориям, чтобы быстро найти нужный шаблон.
5. Выберите шаблон — текст автоматически вставится в поле ввода с подставленными переменными.
6. При необходимости отредактируйте сообщение и отправьте.

**Дополнительные возможности окна шаблонов:**

* **Строка поиска** — по ключевым словам.
* **Фильтрация по категориям**.
* **Настройка отображения** — показывать только названия или названия + текст.
* **Режим вставки**:
  * Вставить и оставить окно открытым.
  * Вставить и закрыть окно.
* **Быстрое создание** нового шаблона прямо из чата.

#### Отправка шаблонов из карточки сущности

Альтернативный способ (удобен при работе со сделками/лидами):

1. Откройте карточку лида, сделки, контакта или компании.
2. Запустите приложение **«Олчат WABA»**.
3. Перейдите на вкладку **«ШАБЛОНЫ»**.
4. Выберите шаблон, заполните переменные при необходимости.
5. Отправьте сообщение.

#### Полезные советы

* **Переменные** значительно ускоряют работу. Используйте их для персонализации (имя клиента, номер заказа, сумма и т.д.).
* Создавайте **категории** по направлениям: «Приветствия», «Уведомления», «Коммерческие предложения», «Автоответы» и т.д.
* Для WABA важно, чтобы шаблоны были заранее одобрены Meta. Обычные быстрые ответы работают только в рамках 24-часового окна сессии.
* Шаблоны с кнопками (быстрые ответы, ссылки, звонок) повышают вовлеченность клиентов.
* Регулярно просматривайте и обновляйте список шаблонов — удаляйте устаревшие.
